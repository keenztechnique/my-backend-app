# My Professional Backend API 🚀

Асинхронное REST API социальной сети (пользователи, посты, комментарии, лайки), спроектированное по лучшим практикам коммерческой разработки на Python.

## 🛠 Стек технологий
* **FastAPI** — современный, быстрый асинхронный веб-фреймворк.
* **PostgreSQL** — надежная реляционная база данных для Production.
* **SQLAlchemy 2.0** — современная ORM с полной поддержкой асинхронности (`asyncpg`) и строгой типизации (`Mapped`).
* **Alembic** — инструмент для асинхронного управления миграциями и схемами БД.
* **Docker & Docker Compose** — контейнеризация приложения и СУБД в изолированной экосистеме.
* **Pydantic v2 & Pydantic Settings** — валидация данных и безопасное управление конфигурацией через `.env`.
* **Pytest & HTTPX** — автоматизированное асинхронное интеграционное тестирование эндпоинтов.
* **Bcrypt & Python-Jose** — безопасное хэширование паролей и авторизация на базе JWT-токенов.

## 🚀 Быстрый запуск (в Docker)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/keenztechnique/my-backend-app.git
   cd my-backend-app
   ```

2. Создайте файл `.env` в корне проекта на основе примера (или переименуйте `.env.example`):
   ```bash
   cp .env.example .env
   ```

3. Запустите всю инфраструктуру одной командой (база данных инициализируется и миграции накатятся автоматически благодаря встроенной задержке):
   ```bash
   docker-compose up --build
   ```

После запуска интерактивная документация Swagger UI будет доступна по адресу: `http://localhost:8000/docs`.

## 🧪 Запуск автоматических тестов
Чтобы запустить асинхронные тесты внутри запущенного Docker-контейнера, выполните:
```bash
docker-compose exec web pytest -v
```
